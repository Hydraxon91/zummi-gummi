# Changelog

## 0.1.0

- Initial standalone extraction.
- `uv_line_guide.py`: clean/labelled/legend PNGs with optional names JSON.
- `uv_color_layout.py`: dark colored UV sheet with deterministic island colors.
- `uv_layout_gate.py`: geometric and raster overlap reporting, bounds and truncation.
- `extras/uv_chart_repair.py`: optional per-chart repair with Blender or Mio3.
- `extras/uv_rebind_names.py`: carry names across a layout change by exact face set.
- Cube fixture and headless Blender smoke test.
