# Cube example

These are generated from `tests/blender/make_fixture.py` with the six cube faces laid
out as a simple 2×3 atlas. They show the two output styles, not a production UV layout.

- `cube_color_1280.png` — colored sheet.
- `cube_line_1280.png` — labelled line guide with `face_1` … `face_6`.
- `cube_legend_1280.png` — island key.

Regenerate with `tests/blender/run.sh` or the commands in the root README.
